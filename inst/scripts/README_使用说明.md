# msProteomiX 使用说明
# ====================
#
# 【快速上手】
#
# 1. 安装
#    - 在 RStudio 中打开 00_安装指南.R，点击 Source 按钮
#    - 等待安装完成 (首次需要几分钟)
#
# 2. 准备数据
#    - 在项目根目录创建 wkdir/ 文件夹
#    - 将搜库软件的结果文件放入 wkdir/ 中
#    - FragPipe: 复制整个输出文件夹 (含 combined_protein.tsv 等)
#    - MaxQuant: 复制 txt/ 文件夹
#    - DIA-NN:   复制 report.pg_matrix.tsv
#
# 3. 运行分析
#    - 按顺序运行脚本 (01 → 02 → 03 → ...)
#    - 每个脚本: 在 RStudio 中双击打开 → 点击 Source 按钮
#    - 01 必须首先运行 (数据导入和分组)
#    - 02-10 可以任意顺序运行
#
# 4. 查看结果
#    - 所有结果保存在 output/ 文件夹
#    - PDF 文件: 图表
#    - CSV 文件: 源数据
#
# ──────────────────────────────────────────────────────
#
# 【脚本列表】
#
#  00_安装指南.R          一键安装所有依赖 (仅需运行一次)
#  01_数据导入与分组.R    读取数据 + 交互式分组 (必须首先运行)
#  02_定性分析_柱状图.R   蛋白/肽段/PSM 鉴定数量柱状图
#  03_Venn维恩图.R        蛋白重叠分析 Venn/UpSet 图
#  04_PCA主成分分析.R     PCA 主成分分析
#  05_CV变异系数.R        定量重复性 CV 箱线图/小提琴图
#  06_相关性热图.R        样品相关性热图
#  07_差异分析_火山图.R   Limma/t-test 差异分析 + 火山图
#  08_序列覆盖度.R        蛋白序列覆盖度分析 (需要 FASTA)
#  09_GO富集分析.R        GO 细胞组分富集气泡图
#
# ──────────────────────────────────────────────────────
#
# 【常见问题】
#
# Q: "Error: 请先运行 01_数据导入与分组.R"
# A: 说明你还没有运行第一步。请先打开并 Source 01 脚本。
#
# Q: "Error: 未找到 combined_protein.tsv"
# A: 请确认你的搜库结果已放入 wkdir/ 文件夹中。
#
# Q: 安装 Bioconductor 包失败
# A: 尝试手动安装:
#    if (!require("BiocManager")) install.packages("BiocManager")
#    BiocManager::install("limma")
#
# Q: 想修改分组怎么办？
# A: 重新运行 01_数据导入与分组.R，选择"重新分组"即可。
#
# Q: 火山图参数怎么调？
# A: 打开 07_差异分析_火山图.R，修改顶部"用户设置"区域的参数。
#
